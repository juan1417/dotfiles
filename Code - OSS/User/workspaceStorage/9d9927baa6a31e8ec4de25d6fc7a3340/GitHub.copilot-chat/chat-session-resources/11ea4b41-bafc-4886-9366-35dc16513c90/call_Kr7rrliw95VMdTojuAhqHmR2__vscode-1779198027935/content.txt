### Async Client for Ollama Python

Source: https://context7.com/ollama/ollama-python/llms.txt

Demonstrates the use of the `AsyncClient` for performing non-blocking chat completions and streaming responses within asynchronous Python applications.

```python
import asyncio
from ollama import AsyncClient

async def main():
    client = AsyncClient()

    # Async chat
    response = await client.chat(
        model='gemma3',
        messages=[{'role': 'user', 'content': 'Why is the sky blue?'}]
    )
    print(response['message']['content'])

    # Async streaming
    async for chunk in await client.chat(
        model='gemma3',
        messages=[{'role': 'user', 'content': 'Tell me a joke'}],
        stream=True
    ):
        print(chunk['message']['content'], end='', flush=True)

asyncio.run(main())
```

### Model Management - Create Custom Model

Source: https://context7.com/ollama/ollama-python/llms.txt

Creates a custom model, either from an existing model with a custom system prompt or as a new model. Supports both non-streaming and streaming for progress updates.

```python
from ollama import Client

client = Client()

# Create from existing model with custom system prompt
response = client.create(
    model='my-assistant',
    from_='gemma3',
    system='You are Mario from Super Mario Bros.',
    stream=False
)
print(response.status)

# Create with streaming progress
for progress in client.create(
    model='custom-model',
    from_='llama3.1',
    system='You are a helpful coding assistant.',
    stream=True
):
    print(progress.status)
```

### Basic Chat Completion with Ollama Python

Source: https://context7.com/ollama/ollama-python/llms.txt

Demonstrates how to perform a basic chat completion with a specified model and user message. It shows how to access the response content as both a dictionary and an object, and how to handle streaming responses.

```python
from ollama import chat, ChatResponse

# Basic chat completion
response: ChatResponse = chat(
    model='gemma3',
    messages=[
        {'role': 'user', 'content': 'Why is the sky blue?'}
    ]
)
print(response.message.content)
# Output: "The sky appears blue because of a phenomenon called Rayleigh scattering..."

# Access response as dict or object
print(response['message']['content'])  # Dict-style access
print(response.message.content)         # Object-style access

# Streaming response
stream = chat(
    model='gemma3',
    messages=[{'role': 'user', 'content': 'Tell me a short story'}],
    stream=True
)
for chunk in stream:
    print(chunk['message']['content'], end='', flush=True)
```

### Custom Client Configuration for Ollama Python

Source: https://context7.com/ollama/ollama-python/llms.txt

Explains how to configure the Ollama Python client with custom host, headers, and authentication, including connecting to local instances or the cloud API using Bearer tokens.

```python
from ollama import Client
import os

# Local Ollama instance
client = Client(
    host='http://localhost:11434',
    headers={'x-custom-header': 'value'}
)

# Cloud API with authentication
client = Client(
    host='https://ollama.com',
    headers={'Authorization': f'Bearer {os.environ.get("OLLAMA_API_KEY")}'}
)

response = client.chat(
    model='gpt-oss:120b',
    messages=[{'role': 'user', 'content': 'Hello!'}]
)
print(response.message.content)

# Environment variables also supported:
# OLLAMA_HOST - sets default host
# OLLAMA_API_KEY - sets default Bearer token
```

### Model Management - List Models

Source: https://context7.com/ollama/ollama-python/llms.txt

Lists all models available on the Ollama instance. It iterates through the response to print details like model name, size, modification time, and other details.

```python
from ollama import list

response = list()
for model in response.models:
    print(f"Model: {model.model}")
    print(f"  Size: {model.size}")
    print(f"  Modified: {model.modified_at}")
```

For applications requiring non-blocking operations, the AsyncClient class provides an asynchronous interface for interacting with Ollama.
